# Household Electric Power Consumption Forecasting using RNN and LSTM

## Project Overview
This project explores time-series forecasting of household electric power consumption using Recurrent Neural Networks (RNNs) and Long Short-Term Memory (LSTM) networks. The notebook covers data preparation, preprocessing, time-series modelling, prediction, and evaluation.

## Objectives
- Load and inspect household electricity-consumption data.
- Clean and prepare the time-series data for modelling.
- Scale numerical features where appropriate.
- Build and train RNN/LSTM models for forecasting.
- Compare predicted values with actual values using suitable evaluation metrics and plots.

## Dataset
The notebook references the **Individual Household Electric Power Consumption** dataset from the UCI Machine Learning Repository.

- Dataset page: https://archive.ics.uci.edu/dataset/235/individual+household+electric+power+consumption
- Archive used in the notebook: https://archive.ics.uci.edu/static/public/235/individual+household+electric+power+consumption.zip

The dataset contains measurements of household electric power consumption recorded over time. Check the dataset documentation and the notebook for the exact columns and time interval used in this project.

## Workflow
1. **Data preparation:** download or load the dataset and inspect its structure.
2. **Cleaning:** handle missing or invalid values and parse date/time fields.
3. **Feature preparation:** select the target variable and relevant input features.
4. **Scaling:** fit a scaler on training data and apply it consistently to training and test data.
5. **Sequence creation:** transform the time series into input windows and prediction targets.
6. **Model building:** create the RNN and/or LSTM architecture used in the notebook.
7. **Training:** train using the training sequences and validation strategy.
8. **Evaluation:** compare forecasts with held-out observations using metrics such as MAE, RMSE, or MSE where implemented.
9. **Visualization:** plot actual versus predicted values to inspect forecast performance.

## Limitations
- Forecast quality depends on data cleaning, sequence length, selected features, and train/test splitting.
- Time-series data should be split chronologically to avoid data leakage.
- Scalers should be fitted only on the training set.
- Results should be interpreted with the chosen target variable and forecast horizon in mind.
